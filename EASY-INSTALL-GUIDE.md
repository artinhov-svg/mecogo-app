# MeCOGO - Easy Installation Guide

## 🎯 Choose Your Installation Method

### Option 1: One-Click Windows Setup (Recommended)
**Requirements:** Just Windows 10/11

1. **Download Node.js:** 
   - Go to https://nodejs.org
   - Download and install the LTS version
   - ✅ This is a one-time setup

2. **Run MeCOGO:**
   - Double-click `setup.bat` (first time only)
   - Double-click `start-mecogo.bat` (every time you want to use it)
   - 🚀 MeCOGO opens automatically in your browser!

### Option 2: Docker (Zero Configuration)
**Requirements:** Docker Desktop

1. **Install Docker Desktop:**
   - Download from https://docker.com/products/docker-desktop
   - Install and start Docker

2. **Run MeCOGO:**
   ```bash
   docker-compose up
   ```
   - 🎉 Access at: http://localhost:3000

### Option 3: Online Demo (No Installation)
**Requirements:** Just a web browser

1. **Deploy Online:**
   - Click the "Publish" button in your development environment
   - Get instant online URL
   - 🌐 Share with anyone, anywhere!

## 🆘 Need Help?

**If setup.bat doesn't work:**
- Install Node.js from https://nodejs.org
- Run setup.bat again

**If start-mecogo.bat doesn't work:**
- Open Command Prompt in the MeCOGO folder
- Type: `yarn dev`

**For instant testing:**
- Use the online deployment option
- No installation required!
